# 🚗 Análisis de Vehículos Usados

Esta aplicación interactiva fue desarrollada con **Streamlit**, **Pandas** y **Plotly** para visualizar y explorar datos de vehículos usados en Estados Unidos. El objetivo es facilitar la comprensión de patrones relacionados con el kilometraje (odómetro) y el precio de los vehículos, lo que puede ser útil para análisis de mercado o toma de decisiones informadas.

## 🧠 Contexto

En el sector automotriz, especialmente en el mercado de autos usados, el análisis de datos juega un papel clave. Factores como el kilometraje y el tipo de vehículo influyen directamente en el precio de venta. Esta app permite visualizar esa relación de forma clara y dinámica, haciendo uso de herramientas modernas de visualización.

## ⚙️ Funcionalidades

- **Carga de datos**: la app utiliza un archivo `vehicles_us.csv` con información detallada sobre autos usados.
- **Visualización de histograma**: permite mostrar un histograma interactivo del odómetro (kilometraje), lo que ayuda a identificar la distribución de kilometrajes en los autos disponibles.
- **Diagrama de dispersión**: se puede activar una gráfica que muestra la relación entre el odómetro y el precio del vehículo. Además, los puntos están coloreados por tipo de vehículo (`SUV`, `sedan`, etc.), lo cual facilita encontrar patrones por categoría.
- **Interfaz sencilla**: gracias a Streamlit, la app es intuitiva y puede ser usada sin conocimientos técnicos.

## 📊 Tecnologías utilizadas

- Python
- Pandas
- Plotly Express
- Streamlit
